# Prepared Researcher source material

The [chat-service source pack](chat-service/scope.md) describes a fictional AI
chat application. Its three files provide a shared starting point for the
[prepared-example walkthrough](../../docs/n8r-surface/researcher-prepared-check.md).
Copy that folder into a fresh run in your own local vault; keep these originals
unchanged. Generated findings and working settings belong in the local vault,
not in this public example directory.

The source pack is authored by AI Surface Model contributors. The repository's
[licensing rules](../../LICENSING.md) apply: prose is CC-BY-4.0 and configuration
examples are Apache-2.0. These are synthetic inputs, not Researcher-generated
findings or evidence of a running application.
