# Retired concept: Bench

Bench is no longer an entity in the current AI Surface Model. A Lab contains
Experiments directly. Each Experiment owns its desired setup and requests
resource configuration from its Lab.

This page preserves the old link destination. Historical records retain their
original identities and evidence; they do not define current ownership or grant
operational authority. See the [overview](README.md), [Lab](lab.md), and
[Experiment setup](experiment.md#requesting-a-setup).
